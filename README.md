# SmartKid Wallet

Nền tảng nhập vai mô phỏng dành cho học sinh lớp 4–5, tích hợp **Toán học + Đạo đức + giáo dục tài chính + ra quyết định**.

## MVP hiện tại

Tập trung làm sâu **một map Siêu thị** theo hai pha:

1. **Learn-to-Unlock** — học sinh hoàn thành bài toán để mở khóa 5 gian hàng.
2. **Full Shift Simulation** — sau khi mở đủ gian, học sinh bước vào một ca làm việc gồm 5–6 khách hàng và các sự kiện ngẫu nhiên.

Tài liệu sản phẩm, luật thiết kế và kiến trúc nằm trong `docs/`. Quy tắc bắt buộc cho coding agents nằm trong `AGENTS.md`.

> Trạng thái: đang khởi tạo nền tảng MVP.
