# AI / Tool Skills to follow

Khi agent tương ứng có skill/tool, phải đọc/áp dụng trước khi làm phần liên quan:

1. **Supabase skill** — bắt buộc với Auth, DB, RLS, Storage, Realtime.
2. **Supabase Postgres best practices** — khi thiết kế/optimize schema và query.
3. **React best practices** — khi tạo hoặc sửa nhiều TSX component.
4. **Game Development Studio / asset production** — khi làm asset, sprite, GLB, texture hoặc pipeline game.
5. **Agent browser verification** — sau khi dev server chạy hoặc khi sửa UI/interaction.
6. **Vercel/hosting skills** — chỉ khi thực sự triển khai trên Vercel.
7. Không tự thêm framework/thư viện lớn nếu chưa ghi rationale vào docs/architecture decision.

Tài liệu repo luôn là source of truth về product behavior. Tool skill là source of truth về cách dùng công nghệ.
