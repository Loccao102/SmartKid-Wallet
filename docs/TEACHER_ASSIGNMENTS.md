# Teacher Assignment — Archived Direction

## Trạng thái

Teacher Assignment không phải core dependency của SmartKid Wallet.

Học sinh phải có thể:
- vào Learning Mode;
- mở gian bằng Toán;
- hoàn thành Mission;
- mở Work Mode

mà không cần giáo viên tạo bài trước.

## Vai trò giáo viên trong Production v1

Ưu tiên:
- quản lý lớp;
- xem progression;
- xem first-attempt accuracy;
- xem skill/attempt;
- xem Mission/Work completion;
- xem fixed-seed research challenge khi được cấp.

Teacher UI tách khỏi student game UI.

## Future optional module

Assignment Builder có thể quay lại như module bổ sung:
- giao Mission có sẵn;
- chọn challenge cùng seed;
- chọn bộ ôn tập;
- deadline.

Nó không được trở thành điều kiện để core game hoạt động.
